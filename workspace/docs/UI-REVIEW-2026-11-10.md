# 同频配色与风格审核

2026-11-10，实现前冻结。用户明确调用Hallmark，要求几套配色和设计风格供审核。本次为独立审核预览，不选定或替换已发布App主题。

## 范围

- 读取v0.1.3/v0.1.2规格，保留真实客户端DOM、图标、消息分组、时间键盘入口、附件入口、成员/设置和紧凑登录。
- 输出四套同内容的聊天及登录：霁蓝（清爽扁平对照）、暖砂（Furrow纸感与赤陶）、石墨（Console深灰琥珀、紧凑）、暮紫（Dusk雾紫石板、柔和）。区别色彩、密度、圆角、导航表面及选中形式。系统中文字体保留，不加载外部字体。
- 审核页提供四图对照、单套可操作预览、聊天/登录切换；明确为演示数据，本机输入只在预览内存流转。复制客户端资源采用固定清单，不接触真实账号/聊天/附件/模型/生产服务。
- 新增outputs/design-review-2026-11-10及专用构建/验证脚本；workspace/client和桌面包保持已发布版本，选择后的落地另开迭代。不删除任何产品文件或路由。

## 验收

1. 四方案同内容、同操作；颜色、字体全部来自主题令牌；深色拆分按钮前景与表面，标志形状保留且随主题配色。
2. 1280×860、960×680批量截取4主题×2界面；无横向溢出，登录无半屏口号，聊天详情默认收起，附件/成员/设置可操作。
3. 正文/次要文字/按钮文字≥4.5:1，焦点/控件边界≥3:1；键盘焦点可见，reduced-motion与无脚本静态对照可用。
4. Hallmark app scope静态与渲染扫描，独立视觉复核；最多一批集中修正及一轮确认。失败/未执行如实保留，预览不冒称生产端到端验收。
5. 预览、可复现脚本、脱敏报告和交接记录commit、新annotated审核tag、push并核验远端。客户端产品版本不因审核预览升级。
