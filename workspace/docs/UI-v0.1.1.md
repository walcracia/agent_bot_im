# v0.1.1 界面精简设计（先于修改）

日期：2026-11-07。依据用户明确要求与红框截图，使用官方 Impeccable 4.8.0，Operate 模式。技能安装 C:/Users/water/.codex/skills/impeccable；context引擎下载失败，按技能的fallback读取项目现有设计，使用 distill / clarify / operate / craft-floor。源：https://github.com/pbakaus/impeccable 。

## 目标与保留

用户只需要登录、找到同事、聊天、发文件。保留同频深绿/暖白色调和微信式分区、现有通讯/管理/助手功能。减少视觉与文案负担；不重新设计品牌，不以隐藏功能实现简洁。

## 确定删除

用户截图中四处全部删除，不用别的说明占原位：

1. 左侧“属于小团队的安静空间……把工作向前推进”介绍段。
2. 登录标题下“连接团队服务器，开始今天的对话”。
3. 按钮下“账号由团队管理员创建，登录凭据仅在本次会话中保留”。
4. 左下“私有部署 · 轻量沟通 · 自由协作”。

同时清理无操作价值的英文眉题、版本页脚、空状态宣传、重复文件规则说明与助手架构说明卡。技能craft-floor禁止眉题；图标采用现有一致描边SVG，不用emoji代替。

## 操作层级

- 登录：品牌/一句标题、账号、密码、登录按钮。团队地址作为独立次要连接设置入口，当前地址有合理默认值，用户需要切换时可发现且键盘可达。常用词“团队地址”“账号”。不将访问地址写成“服务器部署”等。
- 聊天：会话列表与消息为主。导航、附件、详情、助手使用一致图标；icon button必须aria-label/title。保留联系人姓名、消息、时间、未读等真实内容。
- 连接状态优先小状态点+悬停提示，异常时短文字“正在重连”。附件大小规则在选择文件出错时提示，不在多处常驻重复。
- 详情默认收起，经图标展开查看成员/文件。无固定说明卡。空状态仅短标题与“新聊天”主操作。
- 助手展示名为“助手”，普通界面不出现SDK、token、监听、DSH等实现名。真实群聊触发仍为@dsh；可用助手图标按钮插入实际@dsh，不能只改展示文案却破坏协议。管理员连接功能按需揭示，称“连接助手”“连接码”，仅生成连接码时显示必要保密/有效期信息。
- 账号创建/错误恢复/上传进度保留必要文字。图标减少视觉文字，但不减少屏幕阅读器和键盘的语义。
