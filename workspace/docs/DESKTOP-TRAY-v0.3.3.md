# v0.3.3 Windows托盘与新消息提醒

2026-11-20，实现前冻结。用户已选择：最小化保留任务栏，关闭窗口收进Windows托盘（截图中的隐藏图标区域）；新消息闪烁提醒。日志自动分析同时设计，但本轮不启动批量QA分析，入口必须为Trigger→Router架构。

## 行为与兼容

- 启动即有清晰品牌托盘图标。最小化按Windows原行为；点击关闭只隐藏，聊天连接保持。点击/双击托盘或“打开同频TeamPlay”恢复窗口；“退出”才真正退出客户端。系统关机/注销正常退出。托盘不可用时不能将窗口隐藏成无法找回的进程。
- 后台收到新消息时托盘图标低频交替未读标记；窗口仍在任务栏时同时调用Windows闪烁提醒。回到窗口停止闪烁，未读徽记按真实未读数保留，不把所有会话强制已读。初次登录历史未读不当新消息闪烁，自己的消息/重复事件不重复提醒。不弹出含聊天正文的系统通知。
- 只有窗口前台、可见、实际打开的聊天才自动标已读；后台/最小化/托盘收到当前聊天消息也保持未读。返回窗口补读消息后只标当前聊天已读；退出登录清除桌面未读状态。
- 单个用户目录只开一个客户端实例，重复打开恢复已有窗口；TEAMRELAY_PROFILE隔离验收仍可独立运行。保留TeamRelay.exe、旧app.setName/用户目录和存储键。
- 沿用石墨界面和已有品牌图形；操作文案仅“打开同频TeamPlay”“退出”，tooltip可显示未读数量，不增加说明页或技术文案。托盘位置由Windows决定，不能承诺固定在屏幕左下/右下或强制显示隐藏区外。

## 实现边界

Electron主进程拥有Tray/Menu/flashFrame和退出生命周期；新增sandbox兼容preload，contextBridge只暴露有限的未读数更新/前台回调。IPC检查主窗口、主frame与本地页面来源，数字/布尔严格校验，不传聊天内容/账号令牌，不暴露任意IPC、shell、路径或Node能力。保留contextIsolation、sandbox、导航与下载限制。

图标从已有logo向量生成本地PNG/ICO并随明确白名单打包；不依赖外网图标。build同步包含preload/托盘模块/图标，ASAR验收清单随实际新增文件更新。网页端缺少桌面桥仍正常运行。
