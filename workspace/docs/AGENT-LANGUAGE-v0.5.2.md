# v0.5.2：三Agent中文交互

2026-11-23，实施前设计。用户要求协调者与DSH、Pi、Hermes使用中文传递信息，作为后续会话和多Agent接续的长期规则。

任务说明、补充、进度、审查发现和结果说明使用简体中文。原生回归模板改中文，并要求summary/findings.detail等说明文字使用中文；JSON字段、枚举、工具名、命令、路径、源码和原始引用保留，避免损坏机器契约。通用Worker和Router显式约定中文说明，QA仅将宿主运输说明改中文，固定原插件取证、system/user及报告原文不翻译或另写。

本轮只改交互语言，不新增Agent/业务流程，不为语言调整重新执行已有收费分析。验收使用现有回归、语法检查和实际Windows便携包/托盘/报告下载检查；普通提示文案不新增镜像单测。版本0.5.2、设计/过程/接续/Git与Release齐全，仍每轮打包。
