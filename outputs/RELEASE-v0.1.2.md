# 同频 v0.1.2

这次更新减少日常界面的常驻信息和重复操作：

- 登录改为紧凑品牌与居中表单，移除半屏标语。
- 附件合并到一个入口，文件、图片、音频和视频均保留；输入框从一行开始按内容增长。
- 收起会话总数和快捷键说明，保留未读数与可访问提示。
- 连续同人消息成组，减少重复头像/姓名；每条消息可用键盘打开完整时间。
- 成员页点击聊天直接进入私聊，已有会话自动复用。
- 增强输入边框与键盘焦点，修正附件菜单关闭时序及消息刷新时的焦点丢失。

Windows x64 便携客户端：解压 `TeamRelay-v0.1.2-win32-x64.zip`，运行完整目录内的 `TeamRelay.exe`。客户端连接已有团队服务器，账号由管理员创建，不含测试账号或聊天数据；SHA-256 见同版本校验文件。客户端未做代码签名。

验证：26 项 Python、12 项桥接、13 项真实 Chrome 界面流程通过；Hallmark app scope 渲染/保留项检查 0 FAIL、0 REFLEX、0 WARN。Windows 包已构建，包内五个客户端文件逐字节与已验收源码一致；本轮未另外操纵原生 EXE 窗口。

源码含可复现的隔离 UI 验收入口、交接资料，以及可切换页面/尺寸的真实截图预览。生产部署和真实模型验收不在本轮范围。
