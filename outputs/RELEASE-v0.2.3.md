# v0.2.3 · 蓝色 Windows App

Windows客户端已打包为0.2.3：登录页、导航、按钮、会话与消息表面统一为蓝色主题，沿用紧凑布局和原有聊天/媒体功能。原生启动背景同步蓝色，不再只停留于源码改动。

完整解压`TeamRelay-v0.2.3-win32-x64.zip`，打开`TeamRelay-win32-x64/TeamRelay.exe`。保留整个文件夹，不能只复制一个EXE；不需要安装Python。已有本机用户继续连接`http://127.0.0.1:18200`并使用原账号。

兼容当前服务/DSH桥接v0.2.2的两小时任务和聊天内“继续修正/取消任务”；这些能力运行在服务与监听端，无需在客户端另行绑定。服务器和DSH不是随便携包附带的数据/进程，新电脑仍需连接已部署服务。

验证见`outputs/VERIFICATION-desktop-v0.2.3.md`：26项Python、122项Node、16项启动编排、主题对比度及Windows原生窗口通过。源码沿用原DSH主题提交并保留合并历史；ZIP及SHA256随Release交付。
