# v0.2.2 · 两小时任务与聊天内接续

代码任务默认上限改为2小时。超时/中断后auto+installed助手继续在线，原群授权成员发送“继续修正”即可沿用原任务、原DSH会话和已有文件接续；“取消任务”结束等待并保留代码。重复旧指令不会自动启动下一次尝试，其他群、机器人和未授权成员不能恢复。

支持旧uncertain任务和监听离线期间已发送的继续消息迁移；没有明确继续指令仍不自动重做。消息确认丢失只重发通知或结果，原会话缺失或无法证明旧进程退出时继续暂停并给出指引。

Windows原子文件替换增加有限重试和所有者校验，非关键状态显示失败不再打断已准备的任务；worker尚未调用前的准备失败会释放本次预留资源。任务账本、原生会话和租约保护继续保留。

现有客户端无需更换。已有绑定请把`harness.runTimeoutMs`更新为7200000并重启监听；分类默认单独限时2分钟，版本探测30秒。恢复说明见`workspace/bridge/README.md`，完整验收见`outputs/VERIFICATION-v0.2.2.md`。本轮不增加执行中实时取消或自动合并/上线。
