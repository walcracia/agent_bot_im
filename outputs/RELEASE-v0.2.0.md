# 同频 v0.2.0 · 团队讨论驱动代码任务

授权项目群中的普通讨论可以被识别为代码任务，无需每条都@助手。只读识别器结合同群近期上下文判断是否需要工作，再由本机已安装DSH的独立headless会话在绑定Git副本中修改、测试并回群。

- 本机交互绑定入口可按编号选择群聊和派任务成员，复用DSH已有认证，不复制密钥或重新安装Desktop。
- 保留旧SDK/mention模式；auto模式对@消息和私聊也判断取消、已解决或闲聊。
- 新实例默认跳过历史消息；分类失败停止；中断不自动重复；最终结果丢确认只重发结果；同一工作副本的worker跨实例互斥。
- 提供配置后的重启入口、严格JSONL会话恢复、有限上下文与可复现的显式真实模型验收脚本。

已实测无@群消息触发本机DSH修改当前仓库隔离副本中的微型代码夹具，独立pytest通过，IM回传及丢确认恢复通过。夹具不是生产缺陷，没有合并或推送业务改动；完整证据见同版本验收报告。

本次更新服务与桥接，Windows聊天客户端继续使用 [v0.1.2](https://github.com/walcracia/agent_bot_im/releases/tag/v0.1.2)。取得源码后，按workspace/bridge/README.md准备独立副本并在本机绑定；真实账号、群和连接码不随Git分发。当前为单项目串行执行，尚未实现完整Super-agent并行调度或自动合并上线。
